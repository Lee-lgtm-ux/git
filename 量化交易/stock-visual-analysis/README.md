# 股市数据可视化分析

这是一个本地前端行情分析工作台，不需要安装依赖。直接用浏览器打开 `index.html`，选择 CSV 文件后，就可以查看 K 线、成交量、累积收益率、均线、布林带、MACD、RSI、KDJ、ADF 单位根检验、LB 白噪声检验、ACF/PACF、区间收益、最大回撤和年化波动。

## 建议 CSV 字段

- `date` 或 `日期`
- `open` 或 `开盘价`
- `high` 或 `最高价`
- `low` 或 `最低价`
- `close` 或 `收盘价`
- `volume` 或 `成交量`

示例数据在 `data/sample.csv`。
