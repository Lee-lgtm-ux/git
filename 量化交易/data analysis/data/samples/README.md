# Sample CSV Data

这里存放小型 CSV 样例，用于演示页面功能、测试脚本输入格式，或作为 README 中的示例数据。

- `benchmark_sample.csv`：对照基准样例。
- `quality_financial_sample.csv`：财务质量因子样例。
- `quality_trend_sample.csv`：质量趋势预测样例。
- `quality_trend_model_comparison.csv`：模型对比结果表。
- `sample_data.csv`：通用股票价格样例。
- `shanghai_index.csv`：上证指数样例。

这些不是完整数据集，完整数据保留在本机。
